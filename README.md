# TalentTwin

TalentTwin is a full-stack employee capability and career intelligence platform built for the Pccoe Hack project.

## Project overview

The application helps organizations understand employee skills, identify role gaps, track evidence-based development trajectories, and surface AI-driven recommendations for learning and career growth.

## Repository structure

- [backend](backend) — Node.js backend API and logic
- [frontend](frontend) — React + Vite frontend application

## Quick start

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm start
```
